# Naming Ceremony Invitation

Mobile-first bilingual (Marathi / English) invitation for the Namkaran Sohala.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Features

- Digital invitation card with Tap-to-open cover and Ganesha artwork
- Marathi / English language toggle (saved in `localStorage`)
- Background music (mute toggle; starts when the card is opened)
- Single couple photo, festive animations (petals, bells, shimmer)
- Add to Calendar (`.ics`), Maps, tap-to-call, WhatsApp share

Replace `public/audio/bg-music.mp3` with your own loop if you prefer a different track.
